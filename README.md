 # U2-ejercicio39
 ### Sistema de Lectores de Códigos de Barras y QR

**Objetivo principal:** Desarrollar un sistema modular en Java que permita integrar diferentes dispositivos de lectura óptica en un punto de venta mediante una interfaz común.

Se implementa la interfaz `LectorOptico` y dos clases concretas (`EscanerLaser` y `CamaraQR`), cada una con su propia lógica simulada de captura de códigos. Además, se desarrolla la clase `PuntoVenta`, encargada de procesar productos utilizando cualquier dispositivo compatible.

El ejercicio aplica **interfaces, polimorfismo, sobrescritura de métodos, asociación entre clases y desacoplamiento**, permitiendo intercambiar dispositivos de lectura sin modificar la lógica principal del sistema.
